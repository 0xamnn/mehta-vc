# Mehta VC

Backing founders. Building possibility.

Static website for Mehta Ventures Capital, including responsive navigation, investment-interest filters, animated graphics, and a founder introduction dialog.

## Preview

Run `python3 -m http.server 8000` from this folder and open http://localhost:8000. No build step or dependencies are required.

The introduction form opens an email draft; it does not submit or store personal information.

Live prototype: https://mehta-vc-founders.jauntycurry2048.chatgpt.site
